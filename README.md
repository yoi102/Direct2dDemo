Direct2dDemo

该 Demo 主要用于验证 Direct2D 在绘制大量基础图形时的渲染速度与性能表现，
并与传统 GDI 绘制方式进行对比。通过该示例，可以直观观察在不同图形数量、不同绘制策略下，
Direct2D 与 GDI 在渲染效率、刷新耗时以及整体流畅度方面的差异。

※当CapStyle.Round 和 非DashStyle.Solid 时、Direct2D的绘制会非常慢 。
